# Labs and practice data

Practice data used in cases lives here, one folder per data set.

## What belongs here

- Synthetic practice logs (generated for learning, containing no real systems or people)
- Small published sample files whose licence allows redistribution
- Sanitised extracts from my own home lab

## What never goes here

- Packet captures (`.pcap`, `.pcapng`). They're gitignored; reports link to the source instead.
- Anything from malware-traffic exercises, or files extracted from them
- Unsanitised logs from my own systems (keep raw copies in a `raw/` folder, which is gitignored)
- Secrets of any kind
